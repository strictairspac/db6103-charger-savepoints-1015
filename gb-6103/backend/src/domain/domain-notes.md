# 公共充电验收口径

桐驿公共充电运维组接收安装方调试台账，各站需独立核对站号和枪口检测资料，再交接送电调度。手工登记时，重复枪口常在后续巡视才发现，错站需要逐条撤销，同一批多个现场的移交时间被绑定。

08:30 收到 TY-1124-站批，08:35 核对四个站号，08:40 录入枪口序列和检测值，08:45 设定演练下限 1000 kΩ，08:50 后台逐站入表，08:52 核对两个通过站与两次搁置，09:05 导出交班单。

使用 PostgreSQL 主键与枪号名册检测重复，保存点覆盖站表与所有枪口写入，有质量失败也回滚。同批剩余通过站可以使用已回滚站曾尝试写入的枪口编号。默认通过 TY-S11、TY-S14，登记 3 个枪口。绝缘下限为模拟调试参数，整批使用数据库暂存表与最终结果快照，供验收培训。

## 跨批次与接替

- 在役站点与枪口跨批次保留。已在役的站号再次送检时整站搁置，不覆盖原枪口；在役枪号被非接替站占用时，占用站整站搁置。
- 送检资料用 `replaces` 标明接替站与旧站的接替关系。接替站先送检也能通过，并沿用旧站对应枪号；旧站随后不再入册，只登记退役。
- 接替站及全部枪口通过后旧站才退役。接替站任一枪口质量不合格即整站搁置，旧站继续在役，同批无关站照常交接。
- 枪号名册（`port_registry`）以枪号为主键并加行锁：两个批次并发争同一枪号时只准一方入册，另一方整站搁置并在原因中写明在役持枪站。
- 批号（`payload.batch`）裁决台账保存原结果。同批号重试沿用原裁决、不重复入册；批号已按其他下限或另一份资料裁决时，重试被拒绝并提示沿用原参数或更换批号。
- 「送电核对单」显示本批实际生效的交接、搁置原因与当前在役名册。
